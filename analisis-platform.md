## 1. Web Platform (HTML)

- Teknologi: HTML
- File: hello.html
- Cara menjalankan: Membuka file menggunakan browser.
- Hasil: Menampilkan tulisan Hello World! pada halaman web.

## 2. Desktop Platform (Java)

- Teknologi: Java
- File: HelloDesktop.java
- Cara menjalankan: Menggunakan IntelliJ IDEA.
- Hasil: Menampilkan tulisan Hello, Desktop Platform! pada console.

## 3. Node.js Platform (JavaScript)

- Teknologi: JavaScript
- File: hello.js
- Cara menjalankan: Menggunakan perintah node hello.js pada terminal.
- Hasil: Menampilkan pesan Hello, JavaScript! pada terminal.

## 4. Kesimpulan

Setiap platform memiliki cara menjalankan program yang berbeda. HTML dijalankan melalui browser, Java dijalankan menggunakan Java Development Kit (JDK), sedangkan JavaScript dijalankan menggunakan Node.js. Meskipun berbeda teknologi, ketiganya dapat digunakan untuk membuat program sederhana Hello World.
